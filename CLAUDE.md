# SevnQuest

## Aturan visual

- Jangan pernah menggunakan ikon, emoji, atau efek "sparkle" (misalnya lucide `Sparkles`, `WandSparkles`, ✨, 💫, 🌟, atau animasi berkilau/twinkle) di UI maupun kode SevnQuest. Pilih ikon atau efek lain yang sesuai.
- Teks arti kata di data kamus (misalnya "sparkle" sebagai terjemahan kanji) boleh tetap ada karena itu isi data, bukan elemen UI.
